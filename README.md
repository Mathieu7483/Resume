
# Portfolio & Online Resume — Mathieu Godalier

Site web personnel et portfolio professionnel développé en HTML5, CSS3 moderne et JavaScript Vanilla. Hébergé sur GitHub Pages, ce projet présente mon parcours, mes compétences en ingénierie logicielle et Machine Learning, ainsi que mes réalisations.

## Fonctionnalités Principales

* Architecture Multi-Pages : Navigation fluide entre les sections À propos, Projets, Mon CV et Contact (`index.html`, `projects.html`, `resume.html`, `contact.html`).
* Design System personnalisé : Utilisation de variables CSS native (`:root`), typographie dynamique (`clamp()`), typographies Google Fonts (Fraunces, Inter, JetBrains Mono) et support du mode sombre/clair.
* Performance & Accessibilité : Code sémantique HTML5 sans dépendances lourdes ni frameworks inutiles pour un chargement instantané.
* Interface Responsive : Adaptée à toutes les tailles d'écran (Desktop, Tablette, Mobile) avec menu burger interactif.
